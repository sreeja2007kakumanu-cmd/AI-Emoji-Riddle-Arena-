# AI Emoji Riddle Arena
### An AI-Based Adaptive Emoji Guessing Game

## Project Description
AI Emoji Riddle Arena is an interactive game where players guess movie titles or phrases using emoji clues. The game uses rule-based logic to adjust difficulty according to player performance.

## Objectives
- Develop an interactive emoji guessing game.
- Implement Easy, Medium, and Hard difficulty levels.
- Track player score and response time.
- Adapt difficulty based on correct and incorrect answers.
- Analyze gameplay data using graphs.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- Pandas
- Matplotlib
- Google Colab

## Graphical Analysis
The project analyzes:
1. Player Accuracy Over Game Rounds
2. AI-Based Difficulty Level Changes
3. Player Response Time Analysis
